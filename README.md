# Sathwik Varma Mudduluri — Portfolio

Personal portfolio site, built with Next.js, TypeScript, and Tamagui. Fully responsive with light/dark theme support.

Figma (original design) - https://www.figma.com/file/JpDwuMMot4tgaK86ecqINw/My-resume?type=design&node-id=0-1&mode=design&t=LHS6vsLVJUIEj4dy-0

## Stack

- [Next.js](https://nextjs.org/) (App Router) + TypeScript
- [Tamagui](https://tamagui.dev/) for UI components and theming
- [Playwright](https://playwright.dev/) for end-to-end tests

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Testing

```bash
npm test
```

## Deployment

Deployed on [Vercel](https://vercel.com/).
